## Purification methods

| Method | Principle | Classic examples |
|---|---|---|
| Crystallisation | different solubilities at high/low temperature | sugar, benzoic acid; *fractional* crystallisation for mixtures |
| Sublimation | solid → vapour directly | camphor, naphthalene, anthracene, benzoic acid |
| Simple distillation | boiling points differ widely | chloroform (334 K) + aniline (457 K) |
| Fractional distillation | boiling points close | crude oil fractions |
| Distillation under reduced pressure | lowers the boiling point; avoids decomposition | **glycerol from spent lye** (soap industry) |
| Steam distillation | steam-volatile, water-immiscible compounds; the mixture boils when $p_{water} + p_{organic} = p_{atm}$ (below 373 K) | **aniline**, o-nitrophenol, essential oils |
| Differential extraction | distribution between two immiscible solvents | organic compound from water using ether (separating funnel) |
| Chromatography | differential adsorption/partition between stationary and mobile phases | column, TLC (adsorption); paper (partition) |

**Retardation factor:** $R_f = \dfrac{\text{distance moved by compound}}{\text{distance moved by solvent front}}$ (always < 1). Colourless spots are made visible with UV light, iodine vapour or reagent sprays (ninhydrin for amino acids).

## Qualitative analysis: Lassaigne's (sodium fusion) test

:::formula Reactions in the sodium extract
$\ce{Na + C + N -> NaCN}$, $\ce{2Na + S -> Na2S}$, $\ce{Na + X -> NaX}$, $\ce{Na + C + N + S -> NaSCN}$
| Element | Test | Observation |
|---|---|---|
| N | extract + $\ce{FeSO4}$, boil, acidify ($\ce{H2SO4}$) | **Prussian blue**, $\ce{Fe4[Fe(CN)6]3}$ |
| S | + lead acetate / acetic acid | black PbS |
| S | + sodium nitroprusside | violet colour |
| N and S together | + $\ce{FeCl3}$ | **blood red**, $\ce{[Fe(SCN)]^{2+}}$ |
| Halogens | boil with $\ce{HNO3}$ (removes CN⁻/S²⁻), then $\ce{AgNO3}$ | AgCl white (soluble in $\ce{NH3}$), AgBr pale yellow (sparingly soluble), AgI yellow (insoluble) |
| P | oxidise with $\ce{Na2O2}$, then $\ce{HNO3}$ + ammonium molybdate | yellow ammonium phosphomolybdate |
:::

## Quantitative analysis (basic principles)

:::formula Percentage formulas ($m$ = mass of compound)
| Element | Method | Formula |
|---|---|---|
| C | Liebig combustion → $\ce{CO2}$ (absorbed by KOH) | $\%C = \dfrac{12}{44}\times\dfrac{m_{\ce{CO2}}}{m}\times100$ |
| H | Liebig → $\ce{H2O}$ (absorbed by anhydrous $\ce{CaCl2}$) | $\%H = \dfrac{2}{18}\times\dfrac{m_{\ce{H2O}}}{m}\times100$ |
| N | **Dumas** → $\ce{N2}$ volume at STP | $\%N = \dfrac{28}{22400}\times\dfrac{V_{\ce{N2}}\ (\text{mL, STP})}{m}\times100$ |
| N | **Kjeldahl** → $\ce{NH3}$ absorbed in acid | $\%N = \dfrac{1.4\times N_{acid}\times V_{acid\ used}\ (\text{mL})}{m}$ |
| Halogen X | **Carius** → AgX | $\%X = \dfrac{A_X}{M_{AgX}}\times\dfrac{m_{AgX}}{m}\times100$ |
| S | Carius → $\ce{BaSO4}$ | $\%S = \dfrac{32}{233}\times\dfrac{m_{\ce{BaSO4}}}{m}\times100$ |
| P | → $\ce{Mg2P2O7}$ | $\%P = \dfrac{62}{222}\times\dfrac{m_{\ce{Mg2P2O7}}}{m}\times100$ |
| O | by difference | $100 - (\text{sum of the others})$ |

**Kjeldahl's method fails** for nitro and azo compounds and for N in a ring (pyridine), because that N isn't converted to ammonium sulphate.
:::

## Common traps

:::trap Mistake alerts
- In the Kjeldahl formula, $N_{acid}$ is the **normality**: 1 M $\ce{H2SO4}$ = 2 N.
- Blood-red colour (N and S together) arises only if there is **less** sodium than needed for separate NaCN and $\ce{Na2S}$.
- Boil with $\ce{HNO3}$ before the halogen test only when N or S is present.
- Steam distillation works for compounds that are **immiscible** with water and volatile in steam.
:::
