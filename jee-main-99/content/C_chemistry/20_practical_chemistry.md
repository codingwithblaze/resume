## Functional-group tests

| Group | Test | Positive result |
|---|---|---|
| Alcoholic –OH | ceric ammonium nitrate | red colour |
| | sodium metal | effervescence ($\ce{H2}$) |
| Phenolic –OH | neutral $\ce{FeCl3}$ | violet/blue/green colour |
| | bromine water | white precipitate (2,4,6-tribromophenol) |
| Carbonyl (any) | 2,4-DNP (Brady's) | orange-yellow precipitate |
| Aldehyde | Tollens' reagent | silver mirror |
| | Fehling's solution | red precipitate ($\ce{Cu2O}$); not for aromatic aldehydes |
| | Schiff's reagent | pink/magenta colour restored |
| Ketone | sodium nitroprusside + NaOH | red/wine-red colour (methyl ketones) |
| –COOH | $\ce{NaHCO3}$ | brisk effervescence ($\ce{CO2}$) |
| | ethanol + conc. $\ce{H2SO4}$ | fruity smell (ester) |
| –NH₂ (1°) | carbylamine ($\ce{CHCl3}$ + KOH) | offensive smell (isocyanide) |
| Aromatic –NH₂ (1°) | azo-dye test: $\ce{NaNO2}$/HCl (0–5 °C), then alkaline β-naphthol | orange-red dye |

## Preparations

| Compound | How (principle) | Appearance |
|---|---|---|
| **Mohr's salt** $\ce{FeSO4.(NH4)2SO4.6H2O}$ | equimolar $\ce{FeSO4}$ + $\ce{(NH4)2SO4}$ in water with **dil. $\ce{H2SO4}$** (prevents hydrolysis of $\ce{Fe^{2+}}$); crystallise | pale green crystals |
| **Potash alum** $\ce{K2SO4.Al2(SO4)3.24H2O}$ | equimolar $\ce{K2SO4}$ + $\ce{Al2(SO4)3}$ with dil. $\ce{H2SO4}$; crystallise | colourless octahedral crystals |
| **Acetanilide** | aniline + acetic anhydride (glacial acetic acid) | white crystals |
| ***p*-Nitroacetanilide** | acetanilide + conc. $\ce{HNO3}$/conc. $\ce{H2SO4}$, kept cold | pale yellow crystals |
| **Aniline yellow** (*p*-aminoazobenzene) | diazotise aniline (0–5 °C), couple with aniline | yellow/orange solid |
| **Iodoform** | ethanol or acetone + $\ce{I2}$ + alkali (e.g. KOH/$\ce{Na2CO3}$), warm | pale yellow crystals, characteristic smell |

## Titrimetric exercises

:::formula Indicators & redox titrations
| Titration | Suitable indicator |
|---|---|
| strong acid vs strong base | phenolphthalein or methyl orange |
| weak acid vs strong base (e.g. $\ce{CH3COOH}$/NaOH) | **phenolphthalein** (pH 8.3–10; colourless → pink) |
| strong acid vs weak base (e.g. HCl/$\ce{NH3}$) | **methyl orange** (pH 3.1–4.4; red → yellow) |

**Oxalic acid vs $\ce{KMnO4}$:** $\ce{2MnO4- + 5C2O4^{2-} + 16H+ -> 2Mn^{2+} + 10CO2 + 8H2O}$. Heat to **60–70 °C**; acidify with dil. $\ce{H2SO4}$. $\ce{KMnO4}$ is a **self-indicator**: the end point is a permanent light pink. $\ce{Mn^{2+}}$ formed catalyses the reaction (autocatalysis).
**Mohr's salt vs $\ce{KMnO4}$:** $\ce{MnO4- + 5Fe^{2+} + 8H+ -> Mn^{2+} + 5Fe^{3+} + 4H2O}$. **No heating** (air would oxidise $\ce{Fe^{2+}}$); dil. $\ce{H2SO4}$ is added.
Mole ratios: $\ce{KMnO4}$ : oxalate = 2 : 5; $\ce{KMnO4}$ : $\ce{Fe^{2+}}$ = 1 : 5.
:::

## Qualitative salt analysis

:::formula Cation group scheme (syllabus cations)
| Group | Group reagent | Cations (precipitate) | Confirmatory tests |
|---|---|---|---|
| 0 | NaOH, heat | $\ce{NH4+}$ ($\ce{NH3}$ gas) | Nessler's reagent → **brown** precipitate |
| I | dil. HCl | $\ce{Pb^{2+}}$ ($\ce{PbCl2}$ white, soluble in hot water) | KI → yellow $\ce{PbI2}$; $\ce{K2CrO4}$ → yellow $\ce{PbCrO4}$ |
| II | $\ce{H2S}$ in dil. HCl | $\ce{Cu^{2+}}$ (CuS black); $\ce{Pb^{2+}}$ (PbS black) | Cu²⁺: $\ce{NH4OH}$ → **deep blue**; $\ce{K4[Fe(CN)6]}$ → chocolate-brown |
| III | $\ce{NH4Cl}$ + $\ce{NH4OH}$ | $\ce{Al^{3+}}$ (white gelatinous $\ce{Al(OH)3}$), $\ce{Fe^{3+}}$ (reddish-brown $\ce{Fe(OH)3}$) | Fe³⁺: $\ce{K4[Fe(CN)6]}$ → **Prussian blue**; KSCN → **blood red**. Al³⁺: blue lake test |
| IV | $\ce{H2S}$ in ammoniacal medium | $\ce{Zn^{2+}}$ (ZnS white), $\ce{Ni^{2+}}$ (NiS black) | Ni²⁺: **dimethylglyoxime → rosy-red**; Zn²⁺: $\ce{K4[Fe(CN)6]}$ → bluish-white |
| V | $\ce{(NH4)2CO3}$ + $\ce{NH4Cl}$/$\ce{NH4OH}$ | $\ce{Ba^{2+}}$, $\ce{Ca^{2+}}$ (white carbonates) | Ba²⁺: $\ce{K2CrO4}$ → yellow; flame **apple green**. Ca²⁺: ammonium oxalate → white; flame **brick red** |
| VI | $\ce{Na2HPO4}$ + $\ce{NH4OH}$ | $\ce{Mg^{2+}}$ (white crystalline $\ce{MgNH4PO4}$) | — |

**Why $\ce{NH4Cl}$ in Group III?** The common-ion effect suppresses $\ce{NH4OH}$ ionisation, keeping $[\ce{OH-}]$ low enough that only the Group III hydroxides (very low $K_{sp}$) precipitate.
:::

:::formula Anion tests (syllabus anions)
| Anion | Preliminary test | Confirmatory test |
|---|---|---|
| $\ce{CO3^{2-}}$ | dil. $\ce{H2SO4}$ → effervescence | $\ce{CO2}$ turns lime water milky |
| $\ce{S^{2-}}$ | dil. $\ce{H2SO4}$ → $\ce{H2S}$ (rotten eggs) | lead acetate paper turns black; sodium nitroprusside → violet |
| $\ce{NO2-}$ | dil. $\ce{H2SO4}$ → brown fumes | KI + starch → blue |
| $\ce{Cl-}$ | conc. $\ce{H2SO4}$ → HCl fumes | $\ce{AgNO3}$ → white precipitate, soluble in $\ce{NH4OH}$; **chromyl chloride test** (orange-red $\ce{CrO2Cl2}$ vapours → yellow $\ce{PbCrO4}$) |
| $\ce{Br-}$ | conc. $\ce{H2SO4}$ → brown $\ce{Br2}$ vapours | $\ce{AgNO3}$ → pale-yellow precipitate (partly soluble in $\ce{NH4OH}$); layer test → orange-brown |
| $\ce{I-}$ | conc. $\ce{H2SO4}$ → violet $\ce{I2}$ vapours | $\ce{AgNO3}$ → yellow precipitate (insoluble); layer test → violet |
| $\ce{NO3-}$ | conc. $\ce{H2SO4}$ + Cu → brown fumes | **brown ring test**: $\ce{[Fe(H2O)5(NO)]^{2+}}$ |
| $\ce{SO4^{2-}}$ | (no gas) | $\ce{BaCl2}$ → white $\ce{BaSO4}$, insoluble in HCl |
:::

## Physical-chemistry experiments (syllabus)

1. **Enthalpy of solution of $\ce{CuSO4}$:** measure the temperature change in a calorimeter; $\Delta H = -\dfrac{(m c + W)\Delta T}{n}$. Anhydrous $\ce{CuSO4}$ dissolves exothermically.
2. **Enthalpy of neutralisation** (strong acid + strong base): about −57.1 kJ per mol of water.
3. **Lyophilic sols** (starch, gum, gelatin: warm with water directly) vs **lyophobic sols** ($\ce{Fe(OH)3}$ by hydrolysis of $\ce{FeCl3}$ in boiling water; $\ce{As2S3}$ by double decomposition).
4. **Kinetics of $\ce{I-}$ + $\ce{H2O2}$:** $\ce{H2O2 + 2I- + 2H+ -> I2 + 2H2O}$. The time for the blue starch–iodine colour to appear (thiosulphate clock) measures the rate at different concentrations.

## Common traps

:::trap Mistake alerts
- Don't heat in the Mohr's salt–$\ce{KMnO4}$ titration. Do heat (60–70 °C) for oxalic acid.
- **HCl is never used** to acidify $\ce{KMnO4}$ titrations (it's oxidised to $\ce{Cl2}$).
- The chromyl chloride test is given by **chlorides only**.
- Nessler's reagent (alkaline $\ce{K2HgI4}$) → **brown** precipitate with $\ce{NH4+}$/$\ce{NH3}$.
- DMG gives a rosy-red precipitate with $\ce{Ni^{2+}}$, not with $\ce{Zn^{2+}}$.
:::

@@Q C20-10 | M | 1.5 | Permanganate–oxalate titration | NV

@@END
