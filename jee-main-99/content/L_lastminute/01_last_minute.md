# Physics in One Page {#lm-physics}

<div class="sheet">

:::cols2
**Mechanics**

$R = \dfrac{u^2\sin2\theta}{g}$ · $H = \dfrac{u^2\sin^2\theta}{2g}$ · $T = \dfrac{2u\sin\theta}{g}$
Banking: $\tan\theta = \dfrac{v^2}{rg}$ · vertical circle: $v_{bottom} \ge \sqrt{5gl}$
Elastic, $m_2$ at rest: $v_1 = \dfrac{m_1 - m_2}{m_1 + m_2}u$, $v_2 = \dfrac{2m_1}{m_1 + m_2}u$
$I$: ring $MR^2$ · disc $\tfrac12MR^2$ · solid sphere $\tfrac25MR^2$ · rod $\tfrac1{12}ML^2$ / $\tfrac13ML^2$
Rolling: $a = \dfrac{g\sin\theta}{1 + k^2/R^2}$ · $L = I\omega$ conserved if $\tau = 0$
$v_o = \sqrt{GM/r}$ · $v_e = \sqrt{2gR}$ · $T^2 \propto r^3$ · $E = -\dfrac{GMm}{2r}$
$g_h \approx g(1 - 2h/R)$ · $g_d = g(1 - d/R)$

**Matter, heat, thermodynamics**

Bernoulli · $v_t = \dfrac{2r^2(\rho - \sigma)g}{9\eta}$ · $h = \dfrac{2T\cos\theta}{r\rho g}$ · drop $\dfrac{2T}{r}$, bubble $\dfrac{4T}{r}$
$W_{iso} = nRT\ln\dfrac{V_2}{V_1}$ · adiabatic $PV^\gamma$ const, $W = \dfrac{P_1V_1 - P_2V_2}{\gamma - 1}$
$\eta = 1 - \dfrac{T_2}{T_1}$ · $v_{rms} = \sqrt{\dfrac{3RT}{M}}$ · $\gamma = 1 + \dfrac2f$
Stefan $\sigma T^4$ · Wien $\lambda_mT = b$ · Newton's cooling is exponential

**Oscillations & waves**

$T = 2\pi\sqrt{m/k}$ · $2\pi\sqrt{l/g}$ · $v = \sqrt{T/\mu}$ · closed pipe: odd harmonics, $f_1 = \dfrac{v}{4L}$
Doppler $f' = f\dfrac{v \pm v_o}{v \mp v_s}$ · beats $\lvert f_1 - f_2\rvert$
+++
**Electricity & magnetism**

Dipole: axial $\dfrac{2kp}{r^3}$, equatorial $\dfrac{kp}{r^3}$ · sheet $\dfrac{\sigma}{2\varepsilon_0}$ · conductor $\dfrac{\sigma}{\varepsilon_0}$
$C = \dfrac{\varepsilon_0A}{d - t + t/K}$ · $U = \tfrac12CV^2$ · sharing: common $V = \dfrac{\sum CV}{\sum C}$
$R \to n^2R$ when stretched $n$ times · $P_{max}$ at $R = r$ · meter bridge $\dfrac{X}{R} = \dfrac{l}{100 - l}$
$B$: wire $\dfrac{\mu_0I}{2\pi r}$ · loop $\dfrac{\mu_0I}{2R}$ · solenoid $\mu_0nI$ · arc $\dfrac{\mu_0I\theta}{4\pi R}$
$r = \dfrac{mv}{qB}$ · $T = \dfrac{2\pi m}{qB}$ · shunt $S = \dfrac{I_gG}{I - I_g}$
$\varepsilon = Blv$ · $\tau_{LR} = L/R$ · $Z = \sqrt{R^2 + (X_L - X_C)^2}$ · $\omega_0 = \dfrac{1}{\sqrt{LC}}$ · $P = V_{rms}I_{rms}\cos\phi$
$\dfrac{E_0}{B_0} = c$ · spectrum: γ, X, UV, visible, IR, micro, radio

**Optics**

Lens $\dfrac1v - \dfrac1u = \dfrac1f$ · mirror $\dfrac1v + \dfrac1u = \dfrac1f$ · $P = \sum P_i$
Prism $\delta_{min}$: $n = \dfrac{\sin\frac{A + \delta}{2}}{\sin\frac A2}$ · thin prism $\delta = (n - 1)A$
YDSE $\beta = \dfrac{\lambda D}{d}$ · slit central width $\dfrac{2\lambda D}{a}$ · Malus $\cos^2\theta$ · Brewster $\tan i_B = n$

**Modern physics & devices**

$E(\text{eV}) = \dfrac{1240}{\lambda(\text{nm})}$ · $K_{max} = h\nu - \phi = eV_0$ · $\lambda_e = \dfrac{12.27}{\sqrt V}$ Å
$E_n = -13.6\dfrac{Z^2}{n^2}$ eV · lines $\dfrac{n(n - 1)}{2}$ · $R = R_0A^{1/3}$ · $T_{1/2} = \dfrac{0.693}{\lambda}$
NAND, NOR universal · $\overline{AB} = \bar A + \bar B$ · full-wave output $2f$
:::

# Physical & Inorganic Chemistry in One Page {#lm-chemistry}

<div class="sheet">

:::cols2
**Physical chemistry**

$\Delta H = \Delta U + \Delta n_gRT$ · $\Delta G = \Delta H - T\Delta S$ · $\Delta G^\circ = -RT\ln K = -nFE^\circ$
$K_p = K_c(RT)^{\Delta n_g}$ (gases only) · $Q < K$: forward
Weak acid $[\ce{H+}] = \sqrt{K_aC}$ · buffer $\text{pH} = \text{p}K_a + \log\dfrac{\text{salt}}{\text{acid}}$
$K_{sp}$: $\ce{AB}$ $s^2$ · $\ce{AB2}$ $4s^3$ · $\ce{A2B3}$ $108s^5$ · common ion lowers $s$
$\Delta T_f = iK_fm$ · $\pi = iCRT$ · $i = 1 + (n - 1)\alpha$
Nernst $E = E^\circ - \dfrac{0.0591}{n}\log Q$ · $\log K = \dfrac{nE^\circ}{0.0591}$ · $\Lambda_m = \dfrac{1000\kappa}{M}$
First order $t_{1/2} = \dfrac{0.693}{k}$ · zero order $t_{1/2} = \dfrac{[A]_0}{2k}$ · 87.5% = 3 half-lives
Arrhenius $\log\dfrac{k_2}{k_1} = \dfrac{E_a}{2.303R}\left(\dfrac1{T_1} - \dfrac1{T_2}\right)$
Nodes: radial $n - l - 1$, angular $l$ · $E_n = -13.6\dfrac{Z^2}{n^2}$ eV
Bond order $\tfrac12(N_b - N_a)$ · paramagnetic: $\ce{O2}$, $\ce{B2}$, $\ce{O2-}$ · $\ce{O2+}$ bond order 2.5
+++
**Inorganic chemistry**

IE exceptions: $\ce{Be} > \ce{B}$, $\ce{N} > \ce{O}$, $\ce{Mg} > \ce{Al}$, $\ce{P} > \ce{S}$ · most negative EGE: $\ce{Cl}$
Isoelectronic: $\ce{N^3-} > \ce{O^2-} > \ce{F-} > \ce{Na+} > \ce{Mg^2+} > \ce{Al^3+}$
Shapes: $\ce{XeF2}$ linear · $\ce{XeF4}$ square planar · $\ce{SF4}$ see-saw · $\ce{ClF3}$ T-shaped · $\ce{XeF6}$ distorted octahedral
Basicity: $\ce{H3PO4}$ 3 · $\ce{H3PO3}$ 2 · $\ce{H3PO2}$ 1 · $\ce{H3BO3}$ Lewis acid
Solid $\ce{PCl5}$ = $\ce{[PCl4]+[PCl6]-}$ · $\ce{B2H6}$: 3c–2e bonds
$\ce{KMnO4}$: acidic $n = 5$, neutral $n = 3$ · $\ce{K2Cr2O7}$ acidic $n = 6$
Spin-only $\mu$: 1.73 · 2.83 · 3.87 · 4.90 · 5.92 BM ($n = 1$ to 5)
CFSE (oct) $= (-0.4t + 0.6e)\Delta_o$ · $\Delta_t = \tfrac49\Delta_o$
Series: $\ce{I-} < \ce{Br-} < \ce{Cl-} < \ce{F-} < \ce{OH-} < \ce{H2O} < \ce{NH3} < \text{en} < \ce{CN-} < \ce{CO}$
$\ce{[Ni(CO)4]}$ tetrahedral, dia · $\ce{[Ni(CN)4]^2-}$ square planar, dia · $\ce{[NiCl4]^2-}$ tetrahedral, para
$\ce{[MA4B2]}$: 2 geometrical · $\ce{[MA3B3]}$: fac/mer · cis-$\ce{[M(AA)2B2]}$: optically active
Colourless: $d^0$, $d^{10}$ ($\ce{Sc^3+}$, $\ce{Ti^4+}$, $\ce{Zn^2+}$) · $\ce{KMnO4}$ colour = charge transfer
Lanthanoids: +3 common · $\ce{Ce^4+}$ oxidant · $\ce{Eu^2+}$, $\ce{Yb^2+}$ reductants · Zr ≈ Hf
$\ce{Cu+}$ disproportionates in water · Mn: max +7 in the 3d series

# Organic Reactions in One Page {#lm-reactions}

<div class="sheet">

:::cols2
**Reagents**

$\ce{H2}$/Lindlar → *cis*-alkene · $\ce{Na}$/liq. $\ce{NH3}$ → *trans*-alkene
$\ce{HBr}$ + peroxide → anti-Markovnikov (HBr only)
cold dilute alkaline $\ce{KMnO4}$ → *syn*-diol (Baeyer) · $\ce{O3}$/$\ce{Zn}$–$\ce{H2O}$ → carbonyls
$\ce{LiAlH4}$ reduces acids, esters, amides, nitriles · $\ce{NaBH4}$: aldehydes and ketones only
PCC: $1^\circ$ → aldehyde · $\ce{K2Cr2O7}/\ce{H+}$: $1^\circ$ → acid, $2^\circ$ → ketone
DIBAL-H: ester/nitrile → aldehyde · $\ce{SOCl2}$: $\ce{ROH -> RCl}$
alcoholic KOH: elimination · aqueous KOH: substitution
$\ce{Br2}$/NaOH on amide: Hofmann (one C fewer) · $\ce{NaNO2}$/HCl, 0–5 °C: diazonium
$\ce{Sn}$/HCl: $\ce{ArNO2 -> ArNH2}$ · Zn(Hg)/HCl or $\ce{NH2NH2}$/KOH: $\ce{C=O -> CH2}$

**Mechanism rules**

SN2: methyl > 1° > 2° > 3°, inversion · SN1: 3° > 2° > 1°, racemisation
Carbocation 3° > 2° > 1° · carbanion the reverse · EWG raises acidity
Aqueous basicity: $\ce{(C2H5)2NH} > \ce{(C2H5)3N} > \ce{C2H5NH2} > \ce{NH3}$ > aniline
+++
**Named reactions**

Aldol: α-H + dilute base · Cannizzaro: no α-H + concentrated base
Reimer–Tiemann: phenol + $\ce{CHCl3}$/NaOH → salicylaldehyde · Kolbe: phenoxide + $\ce{CO2}$ → salicylic acid
Sandmeyer: $\ce{ArN2+}$ + CuX → ArX · coupling with phenol → orange azo dye
Gabriel: 1° aliphatic amines only · HVZ: α-halo acid · Wurtz: 2RX + 2Na → R–R
Friedel–Crafts: $\ce{AlCl3}$ (not on aniline or nitrobenzene)
Rosenmund: $\ce{RCOCl}$ → RCHO · Stephen: RCN → RCHO · Etard / Gattermann–Koch → benzaldehyde
Williamson: $\ce{RONa + R'X}$ ($\ce{R'X}$ primary)

**Tests**

Tollens': all aldehydes, HCOOH · Fehling's: aliphatic aldehydes only
Iodoform: $\ce{CH3CO-}$ or $\ce{CH3CH(OH)-}$ (ethanol, acetone, 2-propanol)
Lucas: 3° immediate, 2° ~5 min, 1° none · neutral $\ce{FeCl3}$: violet with phenols
$\ce{NaHCO3}$: $\ce{CO2}$ with acids · Hinsberg: 1° soluble in alkali, 2° insoluble, 3° no reaction
Carbylamine: 1° amines only · Lassaigne: N gives Prussian blue
Biomolecules: sucrose non-reducing · denaturation keeps 1° structure · RNA has U instead of T
:::

# Maths in One Page {#lm-maths}

<div class="sheet">

:::cols2
**Algebra**

$\alpha + \beta = -\tfrac ba$, $\alpha\beta = \tfrac ca$ · $\lvert z_1z_2\rvert = \lvert z_1\rvert\lvert z_2\rvert$ · $1 + \omega + \omega^2 = 0$
$\lvert kA\rvert = k^n\lvert A\rvert$ · $\lvert\operatorname{adj}A\rvert = \lvert A\rvert^{n-1}$ · $(AB)^{-1} = B^{-1}A^{-1}$
$\lvert A\rvert = 0$ and $(\operatorname{adj}A)B = 0$ → check for infinitely many solutions
$^nC_r$, $\dfrac{n!}{p!q!}$, circular $(n - 1)!$ · identical into $r$ groups: $^{n+r-1}C_{r-1}$
$T_{r+1} = {}^nC_rx^{n-r}y^r$ · $\sum{}^nC_r = 2^n$
AP $S_n = \tfrac n2[2a + (n - 1)d]$ · GP $S_\infty = \dfrac{a}{1 - r}$ · AM ≥ GM
Relations on $n$ elements: $2^{n^2}$ · reflexive $2^{n^2 - n}$

**Calculus**

$\lim\dfrac{\sin x}{x} = 1$ · $1^\infty$: $e^{\lim g(f - 1)}$ · $1 - \cos kx \approx \tfrac{k^2x^2}{2}$
$(\tan^{-1}x)' = \dfrac{1}{1 + x^2}$ · $(\sin^{-1}x)' = \dfrac{1}{\sqrt{1 - x^2}}$
$\int e^x(f + f') = e^xf$ · $\int\dfrac{dx}{x^2 + a^2} = \dfrac1a\tan^{-1}\dfrac xa$
King: $\int_a^bf(x) = \int_a^bf(a + b - x)$ · odd function on $[-a, a]$: 0
Area $y^2 = 4ax$, $x^2 = 4by$: $\tfrac{16ab}{3}$ · $y = x^2$ and $y = mx$: $\tfrac{m^3}{6}$
Linear DE: IF $= e^{\int P}$ · $P = \tfrac1x \to x$ · $P = \tan x \to \sec x$
+++
**Coordinate geometry**

$d = \dfrac{\lvert ax_1 + by_1 + c\rvert}{\sqrt{a^2 + b^2}}$ · parallel lines: equalise the coefficients first
Circle: centre $(-g, -f)$, $r = \sqrt{g^2 + f^2 - c}$ · chord $2\sqrt{r^2 - d^2}$
Parabola $y^2 = 4ax$: focus $(a, 0)$, latus rectum $4a$
Ellipse: $b^2 = a^2(1 - e^2)$ · hyperbola: $b^2 = a^2(e^2 - 1)$ · latus rectum $\dfrac{2b^2}{a}$

**3D & vectors**

$l^2 + m^2 + n^2 = 1$ · SD $= \dfrac{\lvert(\vec a_2 - \vec a_1)\cdot(\vec b_1\times\vec b_2)\rvert}{\lvert\vec b_1\times\vec b_2\rvert}$
Foot: $Q(\lambda)$ with $\vec{PQ}\cdot\vec b = 0$ · image $2Q - P$
Projection $\dfrac{\vec a\cdot\vec b}{\lvert\vec b\rvert}$ · triangle $\tfrac12\lvert\vec{AB}\times\vec{AC}\rvert$ · $\lvert a\times b\rvert^2 + (a\cdot b)^2 = a^2b^2$

**Statistics, probability, trigonometry**

$\sigma^2 = \dfrac{\sum x^2}{n} - \bar x^2$ · $y = ax + b$: $\sigma_y = \lvert a\rvert\sigma_x$ · naturals: $\dfrac{n^2 - 1}{12}$
Bayes: chosen path ÷ sum of paths · $E(X) = \sum xp$ · $\operatorname{Var} = E(X^2) - \mu^2$
$a\sin x + b\cos x \in [-\sqrt{a^2 + b^2}, \sqrt{a^2 + b^2}]$ · $\cos^{-1}(-x) = \pi - \cos^{-1}x$
$\sin^{-1}x + \cos^{-1}x = \tfrac\pi2$ · $\sin^{-1}(\sin x) = x$ only on $[-\tfrac\pi2, \tfrac\pi2]$
:::

</div>

# Shortcut Checklist {#lm-shortcuts}

<div class="sheet">

Before solving any MCQ the long way, run down this list (Speed Manual, page [[speed-manual]]).

:::cols2
[ ] **Dimensions:** do the options differ in dimensions? Eliminate.
[ ] **Limiting cases:** push a mass, angle or distance to 0, ∞ or equality. Test two limits.
[ ] **Special values:** $n = 1, 2$ or $x = 0, \tfrac\pi4$ in identity-type options.
[ ] **Back-substitution:** are the options numbers that are quick to check?
[ ] **Symmetry:** can $x \to a + b - x$, or a symmetric circuit, cut the work?
[ ] **Estimation:** are the options a factor of 2 or more apart? One significant figure.
[ ] **Ratios:** is only one quantity changing? Use the power law.
[ ] **Conservation first:** is a speed or height asked? Energy/momentum before forces.
+++
[ ] **Standard results:** is this a textbook case (rolling, area, μ values)?
[ ] **Graph:** "number of solutions"? Sketch both sides.
[ ] **n-factor:** titration or redox? Equivalents, not equations.
[ ] **pH:** buffer? $\text{p}K_a + \log$(ratio). Very dilute? pH stays below 7 for an acid.
[ ] **Organic:** products given? Work backwards.
[ ] **Impossibility:** probability > 1? Efficiency ≥ 1? Wrong sign?
[ ] **Casting out nines** on long NV arithmetic.
[ ] **Cancel before multiplying.** Keep exact values until the end.
:::

</div>

# Mistake Checklist {#lm-mistakes}

<div class="sheet">

:::cols2
**The eight types: one-line prevention**

[ ] **CG · Concept:** am I sure which principle applies here?
[ ] **FR · Recall:** does the formula's **condition** hold?
[ ] **CA · Calculation:** every step written; verified by substitution or estimate?
[ ] **MR · Misreading:** asked quantity and NOT/EXCEPT underlined?
[ ] **TR · Transcription:** screen = rough sheet (letter, value, sign)?
[ ] **TS · Time:** past 3 minutes? Leave it.
[ ] **GU · Guessing:** two options eliminated? If not, don't attempt.
[ ] **PR · Pressure:** stuck or panicking? 60-second reset.
+++
**The most costly slips**

[ ] cm ↔ m, kJ ↔ J, mL ↔ L, °C ↔ K
[ ] Lens vs mirror formula; drop vs bubble
[ ] Closed pipe = odd harmonics only
[ ] $\Delta n_g$ counts gases only; $n$-factor of $\ce{KMnO4}$ depends on the medium
[ ] Principal value of $\cos^{-1}$ lies in $[0, \pi]$
[ ] The $+1$ when counting terms; the $\tfrac12$ in triangle areas
[ ] $T_{r+1}$: the 5th term uses $r = 4$
[ ] $d$ vs $d^2$ and radius vs diameter: answer what is asked
[ ] "Incorrect statement" questions: pick the false one
:::
