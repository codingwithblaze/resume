# How the Plans Work {#long-plans}

Every plan in this part is built from the same parts: the five phases of the roadmap (page [[roadmap]]), the chapter order below, and a **block system** that turns one plan into its 6 h, 8 h and 10 h variants. All plans are recommendations {{tag:rec}}. Adjust them with the Plan Selector (page [[plan-selector]]) and your weekly review.

## The block system (6 h · 8 h · 10 h)

A **block** is a focused session of about 2 hours (or 1–1.5 hours on school days) with a written target. Every day in every plan lists its blocks in priority order:

| Variant | Blocks per day | Which blocks you do |
|---|---|---|
| **6 h** | 3 blocks of 2 h (or 4 shorter blocks on school days) | Blocks **1–3** only |
| **8 h** | 4 blocks | Blocks **1–4** |
| **10 h** | 5 blocks | Blocks **1–5** |
| **Hybrid** (6 h weekdays, 10 h weekends) | 3 on weekdays, 5 on Sat–Sun | Tasks marked **W** move to the weekend |

:::important What the 6 h variant gives up
The 6 h variant covers the **same chapters** in the same weeks, but with fewer practice questions per chapter and fewer extension sets. It relies more on the Must-do models. If your mock scores stall on the 6 h variant, the first fix is **selection and accuracy**, not more hours.
:::

| Activity | Phase 1 · Build (6 / 8 / 10 h) | Phase 2 · Strengthen | Phase 3 · Mock & Fix | Phase 4 · Peak |
|---|---|---|---|---|
| New learning | 2 / 2.5 / 3 h | 0.5 / 1 / 1 h (second pass) | — | — |
| Practice & PYQs | 2.25 / 3 / 4 h | 3 / 4 / 5 h | 2 / 3 / 4 h (targeted repair) | 1 / 1.5 / 2 h |
| Revision (R0–R4) | 1 / 1.5 / 1.75 h | 1.5 / 2 / 2.5 h | 1.5 / 2 / 2.5 h | 2.5 / 3.5 / 4.5 h |
| Mistake Book | 0.25 / 0.5 / 0.5 h | 0.25 / 0.25 / 0.5 h | 0.5 / 0.5 / 0.5 h | 0.5 / 0.5 / 0.5 h |
| Tests & analysis (weekly average) | 0.5 / 0.5 / 0.75 h | 0.75 / 0.75 / 1 h | 2 / 2 / 2.5 h | 2 / 2.5 / 2.5 h |

## The chapter order

The order interleaves heavy and light chapters, so every week has one demanding chapter per subject at most. It follows the sequence in which ideas build on each other (e.g. GOC before the organic reaction chapters, calculus before area and DEs).

:::cols3
**Physics**

P01 → P02 → P03 → P04 → P05 → P06 → P07 → P08 → P09 → P10 → P11 → P12 (+ P20) → P13 → P14 → P15 → P16 → P17 → P18 → P19
+++
**Chemistry**

C01 → C02 → C03 → C09 → C04 → C05 → C06 → C07 → C08 → C14 → C13 → C15 → C16 → C10 → C11 → C12 → C17 → C18 → C19 → C20
+++
**Mathematics**

M01 → M02 → M03 → M04 → M05 → M06 → M07 → M08 → M09 → M14 → M10 → M11 → M12 → M13
:::

:::tip Already studied some chapters at school or coaching?
Don't skip them. Do the module's **chapter test first**. Score ≥ 80%: do only the practice set and PYQs, which frees 50–70% of that chapter's time for weaker ones. Score below 60%: study the module in full.
:::

:::
