# Sources & References {#sources}

## How to read the labels in this book

:::grid3
{{tag:verified}}

Taken from an **official** document (NTA, JoSAA, NCERT), or from a news report that quotes one. Re-check it against the 2027 bulletin when it is released (page [[exam-facts]]).
+++
{{tag:third}}

From **third-party** analyses: coaching institutes, education portals and PYQ archives. Useful but approximate; different analysts group topics differently.
+++
{{tag:rec}}

This book's **recommendation**: a strategy, plan, estimate or ranking derived from the sources and from standard preparation practice. It is a judgement, not a fact.
:::

All web sources were accessed in September 2026. Codes in square brackets in the text (e.g. [NTA-IB26]) refer to the entries below. **No question in this book is reproduced from a past paper.** Past papers are referenced only as sources to practise from.
