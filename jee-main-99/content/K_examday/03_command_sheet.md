**THE ROUNDS**

**R1 · sure marks:** the method is visible in about 20 s and it takes ≤ 2 min. Otherwise mark **S** and move on.
**R2 · medium:** at most **3 minutes** each, then leave it.
**R3 · last 20 min:** questions with partial progress; MCQ only with **2 options eliminated**.

**THE RULES**

- Underline the **asked quantity** and any **NOT / INCORRECT / EXCEPT**.
- Read the last line again before marking an answer.
- **NV:** enter only a solved answer. Check value, sign and rounding.
- Never chase a lost question: 4 marks isn't worth 20 minutes.
- Change an answer only for a **specific error** you've found.

**LAST 20 MIN →** no new long questions · check every NV entry · check the palette.
**LAST 10 MIN →** verification only · all responses saved.

**PANIC RESET (60 s)**

Pen down → 5 slow breaths → read only the last line of the next question → do the next *easy* question. **A hard paper is hard for the whole shift.** Normalisation handles it.
