# Chemistry Formula & Fact Sheets {#fh-chemistry}

## Physical Chemistry

:::formula C01–C02 · Mole concept & atomic structure · pages [[c01]], [[c02]]
| Result | Formula |
|---|---|
| Moles | $n = \dfrac{m}{M} = \dfrac{N}{N_A} = \dfrac{V_{\text{gas, STP}}}{22.7\ \text{L}}$ (IUPAC STP, 1 bar) · 22.4 L at 1 atm and 273 K |
| Concentration | $M = \dfrac{n_{solute}}{V(\text{L})}$ · $m = \dfrac{n_{solute}}{\text{kg solvent}}$ · $M = \dfrac{10\,x\,d}{M_{solute}}$ ($x$ = % w/w, $d$ in g/mL) |
| Equivalents | $n$-factor method: $\text{equivalents} = n\times n\text{-factor}$ · $N = M\times n$-factor |
| Photon & Bohr | $E = h\nu$ · $E_n = -13.6\dfrac{Z^2}{n^2}$ eV · $r_n = 0.529\dfrac{n^2}{Z}$ Å |
| Uncertainty & de Broglie | $\Delta x\,\Delta p \ge \dfrac{h}{4\pi}$ · $\lambda = \dfrac hp$ |
| Nodes | radial $n - l - 1$ · angular $l$ · total $n - 1$ |
| Orbital angular momentum | $\sqrt{l(l + 1)}\,\dfrac{h}{2\pi}$ · spin-only moment $\mu = \sqrt{n(n + 2)}$ BM |
:::

:::formula C03 · Chemical bonding · page [[c03]]
| Result | Formula / rule |
|---|---|
| Hybridisation (central atom) | steric number $=$ bond pairs $+$ lone pairs: 2 $sp$ · 3 $sp^2$ · 4 $sp^3$ · 5 $sp^3d$ · 6 $sp^3d^2$ |
| Bond order (MOT) | $\tfrac12(N_b - N_a)$ · paramagnetic if unpaired MO electrons: $\ce{O2}$, $\ce{B2}$, $\ce{O2^-}$ |
| Dipole moment | $\mu = q\times d$ · zero for symmetrical shapes ($\ce{CO2}$, $\ce{BF3}$, $\ce{CH4}$, $\ce{SF6}$, $\ce{XeF4}$) |
| Formal charge | $V - L - \tfrac12B$ |
| Bond angle order | $\ce{CH4}$ (109.5°) $>$ $\ce{NH3}$ (107°) $>$ $\ce{H2O}$ (104.5°) — lone pairs compress angles |
:::

:::formula C04 · Thermodynamics · page [[c04]]
| Result | Formula |
|---|---|
| First law | $\Delta U = q + w$ (IUPAC sign: $w$ done **on** the system) · $w = -P_{ext}\Delta V$ |
| Enthalpy | $\Delta H = \Delta U + \Delta n_gRT$ |
| Reversible isothermal | $w = -2.303\,nRT\log\dfrac{V_2}{V_1}$ |
| Hess & bond enthalpy | $\Delta_rH = \sum\Delta_fH(\text{products}) - \sum\Delta_fH(\text{reactants}) = \sum BE(\text{broken}) - \sum BE(\text{formed})$ |
| Entropy | $\Delta S = \dfrac{q_{rev}}{T}$ · phase change $\Delta S = \dfrac{\Delta H}{T}$ |
| Gibbs | $\Delta G = \Delta H - T\Delta S$ · $\Delta G^\circ = -RT\ln K = -2.303RT\log K$ · $\Delta G^\circ = -nFE^\circ$ |
| Spontaneity | $\Delta H < 0$, $\Delta S > 0$: always · $\Delta H > 0$, $\Delta S > 0$: above $T = \dfrac{\Delta H}{\Delta S}$ |
:::

:::formula C05 · Solutions · page [[c05]]
| Property | Formula |
|---|---|
| Raoult's law | $p_A = x_Ap_A^\circ$ · relative lowering $\dfrac{p^\circ - p}{p^\circ} = x_{solute}$ |
| Elevation / depression | $\Delta T_b = iK_bm$ · $\Delta T_f = iK_fm$ |
| Osmotic pressure | $\pi = iCRT$ |
| van 't Hoff factor | association $i = 1 - \alpha\left(1 - \dfrac1n\right)$ · dissociation $i = 1 + (n - 1)\alpha$ |
| Henry's law | $p = K_Hx$ (higher $K_H$ → lower solubility) |
| Deviations | positive (A–B weaker than A–A, B–B): $\Delta H_{mix} > 0$, minimum-boiling azeotrope · negative: $\Delta H_{mix} < 0$, maximum-boiling azeotrope |
:::

:::formula C06 · Equilibrium · page [[c06]]
| Result | Formula |
|---|---|
| $K_p$ and $K_c$ | $K_p = K_c(RT)^{\Delta n_g}$ |
| Reaction quotient | $Q < K$: forward · $Q > K$: backward |
| Weak acid | $[\ce{H+}] = \sqrt{K_aC}$ · $\alpha = \sqrt{K_a/C}$ (Ostwald, small $\alpha$) |
| pH | $\text{pH} + \text{pOH} = 14$ (25 °C) · $K_w = 10^{-14}$ |
| Buffers | $\text{pH} = \text{p}K_a + \log\dfrac{[\text{salt}]}{[\text{acid}]}$ · $\text{pOH} = \text{p}K_b + \log\dfrac{[\text{salt}]}{[\text{base}]}$ |
| Salt hydrolysis | WA–SB: $\text{pH} = 7 + \tfrac12(\text{p}K_a + \log C)$ · SA–WB: $7 - \tfrac12(\text{p}K_b + \log C)$ · WA–WB: $7 + \tfrac12(\text{p}K_a - \text{p}K_b)$ |
| Solubility | $\ce{AB}$: $K_{sp} = s^2$ · $\ce{AB2}$: $4s^3$ · $\ce{A2B3}$: $108s^5$ · precipitation if $Q_{sp} > K_{sp}$ |
:::

:::formula C07 · Electrochemistry · page [[c07]]
| Result | Formula |
|---|---|
| Cell emf | $E^\circ_{cell} = E^\circ_{cathode} - E^\circ_{anode}$ (reduction potentials) |
| Nernst | $E = E^\circ - \dfrac{0.0591}{n}\log Q$ (298 K) · at equilibrium $\log K = \dfrac{nE^\circ}{0.0591}$ |
| Conductance | $\kappa = \dfrac{G^*}{R}$ ($G^* = l/A$) · $\Lambda_m = \dfrac{1000\,\kappa}{M}$ (S cm² mol⁻¹) |
| Kohlrausch | $\Lambda_m = \Lambda_m^\circ - A\sqrt C$ (strong) · $\Lambda^\circ_m = \sum\nu_i\lambda_i^\circ$ · $\alpha = \dfrac{\Lambda_m}{\Lambda_m^\circ}$ |
| Faraday | $m = \dfrac{MIt}{nF}$ · $F = 96485$ C/mol |
:::

:::formula C08 · Chemical kinetics · page [[c08]]
| Order | Integrated law | Half-life | Units of $k$ |
|---|---|---|---|
| 0 | $[A] = [A]_0 - kt$ | $\dfrac{[A]_0}{2k}$ | mol L⁻¹ s⁻¹ |
| 1 | $k = \dfrac{2.303}{t}\log\dfrac{[A]_0}{[A]}$ | $\dfrac{0.693}{k}$ | s⁻¹ |
| $n$ | — | $\propto [A]_0^{1-n}$ | (mol L⁻¹)$^{1-n}$ s⁻¹ |

Arrhenius $k = Ae^{-E_a/RT}$ · $\log\dfrac{k_2}{k_1} = \dfrac{E_a}{2.303R}\left(\dfrac{1}{T_1} - \dfrac{1}{T_2}\right)$ · first order: 99.9% completion $\approx 10\,t_{1/2}$.
:::

## Inorganic Chemistry: trends & exceptions

:::ref C09 · Periodicity · page [[c09]]
| Property | Trend | Exceptions to remember |
|---|---|---|
| Atomic radius | decreases across a period, increases down a group | $\ce{Ga} \approx \ce{Al}$ (d-contraction) · 4d ≈ 5d (lanthanoid contraction) |
| Ionisation enthalpy | increases across a period | $\ce{Be} > \ce{B}$, $\ce{N} > \ce{O}$ (and $\ce{Mg} > \ce{Al}$, $\ce{P} > \ce{S}$) |
| Electron gain enthalpy | more negative across a period | $\ce{Cl} > \ce{F}$ (most negative is Cl) · noble gases and $\ce{N}$: positive or near zero |
| Electronegativity | increases across a period | $\ce{F}$ highest (4.0, Pauling) |
| Isoelectronic ions | size decreases as $Z$ increases | $\ce{N^3-} > \ce{O^2-} > \ce{F-} > \ce{Na+} > \ce{Mg^2+} > \ce{Al^3+}$ |
:::

:::ref C10–C12 · p-, d-, f-block & coordination · pages [[c10]], [[c11]], [[c12]]
| Topic | Key facts |
|---|---|
| Inert-pair effect | stability of the lower state increases down groups 13–15: $\ce{Tl+}$, $\ce{Pb^2+}$, $\ce{Bi^3+}$ |
| Oxoacid strength | $\ce{HClO4} > \ce{HClO3} > \ce{HClO2} > \ce{HClO}$ · hydrogen-halide acidity $\ce{HI} > \ce{HBr} > \ce{HCl} > \ce{HF}$ |
| Hydrides | thermal stability $\ce{NH3} > \ce{PH3} > \ce{AsH3}$ · boiling point $\ce{H2O} > \ce{H2Te} > \ce{H2Se} > \ce{H2S}$ |
| d-block | magnetic moment $\sqrt{n(n + 2)}$ BM · $\ce{Mn}$ shows +7 · $\ce{KMnO4}$: acidic $\to \ce{Mn^2+}$ ($n = 5$), neutral/weakly basic $\to \ce{MnO2}$ ($n = 3$) |
| $\ce{K2Cr2O7}$ | orange; $\ce{Cr2O7^2-} \rightleftharpoons \ce{CrO4^2-}$ (yellow) with pH · acidic $\to \ce{Cr^3+}$ ($n = 6$) |
| Lanthanoids | common state +3 · Ce +4 (oxidant) · Eu, Yb +2 · lanthanoid contraction |
| Coordination: CFSE (octahedral) | $(-0.4n_{t_{2g}} + 0.6n_{e_g})\Delta_o$ · $\Delta_t = \tfrac49\Delta_o$ |
| Spectrochemical series | $\ce{I-} < \ce{Br-} < \ce{Cl-} < \ce{F-} < \ce{OH-} < \ce{H2O} < \ce{NH3} < \text{en} < \ce{CN-} < \ce{CO}$ |
| Isomer counts | $\ce{[MA4B2]}$: 2 geometric · $\ce{[MA3B3]}$: fac/mer · $\ce{[M(AA)2B2]}$: cis is optically active (3 stereoisomers) |
:::
