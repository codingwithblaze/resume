## The frequently forgotten list {{tag:rec}}

These are the formulas students most often confuse or forget under time pressure, based on the traps collected in the modules. Revise this list in the last week and again on exam eve.

:::trap Physics
| Often confused | Correct version |
|---|---|
| Lens vs mirror formula | lens $\dfrac1v - \dfrac1u = \dfrac1f$ · mirror $\dfrac1v + \dfrac1u = \dfrac1f$ |
| Drop vs soap bubble | excess pressure $\dfrac{2T}{r}$ (drop, one surface) vs $\dfrac{4T}{r}$ (bubble, two surfaces) |
| Closed vs open pipe | closed: odd harmonics only, $f_1 = \dfrac{v}{4L}$ · open: all harmonics, $f_1 = \dfrac{v}{2L}$ |
| $g$ at height vs depth | height: $\left(1 - \dfrac{2h}{R}\right)$ · depth: $\left(1 - \dfrac dR\right)$ |
| Axial vs equatorial dipole field | axial $\dfrac{2kp}{r^3}$ · equatorial $\dfrac{kp}{r^3}$ (and opposite to $\vec p$) |
| $v_{rms}$ vs $v_{mp}$ | $\sqrt{3RT/M}$ vs $\sqrt{2RT/M}$ |
| Wire vs loop field | wire $\dfrac{\mu_0I}{2\pi r}$ · loop centre $\dfrac{\mu_0I}{2R}$ |
| Moment of inertia of a rod | about the centre $\tfrac1{12}ML^2$ · about an end $\tfrac13ML^2$ |
| Photoelectric | $K_{max}$ depends on frequency · current depends on intensity |
:::

:::trap Chemistry
| Often confused | Correct version |
|---|---|
| Sign of work | chemistry (IUPAC): $\Delta U = q + w$, with $w$ done **on** the system · physics: $\Delta Q = \Delta U + W$, with $W$ done **by** the gas |
| Nernst sign | $E = E^\circ - \dfrac{0.0591}{n}\log Q$ (minus, and $Q$ = products over reactants) |
| Molarity vs molality | per litre of **solution** vs per kg of **solvent** |
| $K_p = K_c(RT)^{\Delta n}$ | $\Delta n$ counts **gaseous** moles only |
| First-order half-life | independent of concentration · zero order: $t_{1/2} \propto [A]_0$ |
| Carbocation vs carbanion order | opposite orders |
| $\ce{NaBH4}$ vs $\ce{LiAlH4}$ | $\ce{NaBH4}$ does not reduce acids or esters |
| Fehling's vs Tollens' | benzaldehyde gives Tollens' but **not** Fehling's |
| Electron gain enthalpy | most negative: $\ce{Cl}$, not $\ce{F}$ |
:::

:::trap Mathematics
| Often confused | Correct version |
|---|---|
| Ellipse vs hyperbola | ellipse $b^2 = a^2(1 - e^2)$ · hyperbola $b^2 = a^2(e^2 - 1)$ |
| $\lvert kA\rvert$ | $k^n\lvert A\rvert$, not $k\lvert A\rvert$ |
| Distributing identical objects | $^{n+r-1}C_{r-1}$ (with zeros allowed), not $r^n$ |
| $T_{r+1}$ | the term number is $r + 1$, so the 5th term uses $r = 4$ |
| Principal range of $\cos^{-1}$ | $[0, \pi]$, so $\cos^{-1}(-x) = \pi - \cos^{-1}x$ |
| Variance under $y = ax + b$ | $a^2\sigma^2$ (the constant $b$ has no effect) |
| $\int_0^{2a}f$ with $f(2a - x) = f(x)$ | $2\int_0^af$ (if $f(2a - x) = -f(x)$: zero) |
| IF of $y' - \dfrac yx = \dots$ | $\dfrac1x$, not $x$ |
:::
