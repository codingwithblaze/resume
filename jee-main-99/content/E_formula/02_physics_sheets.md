:::formula P02 · Kinematics · page [[p02]]

:::formula P03 · Laws of Motion · page [[p03]]
| Result | Formula |
|---|---|
| Newton's second law | $\vec F = \dfrac{d\vec p}{dt} = m\vec a$ (constant mass) · impulse $= \Delta p = \int F\,dt$ |
| Friction | $f_s \le \mu_sN$ · $f_k = \mu_kN$ · angle of repose $\tan\theta = \mu_s$ |
| Incline (rough) | block slides if $\tan\theta > \mu_s$ · $a = g(\sin\theta - \mu_k\cos\theta)$ |
| Atwood machine | $a = \dfrac{(m_1 - m_2)g}{m_1 + m_2}$ · $T = \dfrac{2m_1m_2g}{m_1 + m_2}$ |
| Banking | $\tan\theta = \dfrac{v^2}{rg}$ (no friction) · $v_{max} = \sqrt{rg\dfrac{\mu + \tan\theta}{1 - \mu\tan\theta}}$ |
| Flat curve | $v_{max} = \sqrt{\mu rg}$ |
| Vertical circle (string) | $v_{bottom} \ge \sqrt{5gl}$ · $v_{top} \ge \sqrt{gl}$ · $T_{bottom} - T_{top} = 6mg$ |
:::

:::formula P04 · Work, Energy & Power · page [[p04]]
| Result | Formula |
|---|---|
| Work | $W = \int\vec F\cdot d\vec s$ · work–energy theorem $W_{net} = \Delta K$ |
| Spring | $U = \tfrac12kx^2$ · springs in series $\dfrac1k = \dfrac1{k_1} + \dfrac1{k_2}$ · parallel $k = k_1 + k_2$ |
| Conservative force | $F = -\dfrac{dU}{dx}$ · stable equilibrium where $\dfrac{d^2U}{dx^2} > 0$ |
| Power | $P = \dfrac{dW}{dt} = \vec F\cdot\vec v$ |
| Collisions (1D) | $e = \dfrac{\text{separation speed}}{\text{approach speed}}$ · elastic, equal masses: velocities exchange |
| Elastic collision, $m_2$ at rest | $v_1 = \dfrac{m_1 - m_2}{m_1 + m_2}u_1$ · $v_2 = \dfrac{2m_1}{m_1 + m_2}u_1$ |
| KE–momentum | $K = \dfrac{p^2}{2m}$ |
:::

|---|---|

| Moments of inertia | ring $MR^2$ · disc $\tfrac12MR^2$ · solid sphere $\tfrac25MR^2$ · hollow sphere $\tfrac23MR^2$ · rod (centre) $\tfrac1{12}ML^2$ · rod (end) $\tfrac13ML^2$ |

| Rolling without slipping | $v = \omega R$ · $K = \tfrac12mv^2\left(1 + \dfrac{k^2}{R^2}\right)$ · on an incline $a = \dfrac{g\sin\theta}{1 + k^2/R^2}$ |

:::formula P06 · Gravitation · page [[p06]]
| Result | Formula |
|---|---|
| Field & potential | $g = \dfrac{GM}{R^2}$ · $V = -\dfrac{GM}{r}$ · $U = -\dfrac{GMm}{r}$ |
| Variation of $g$ | height $g_h = \dfrac{g}{(1 + h/R)^2} \approx g\left(1 - \dfrac{2h}{R}\right)$ · depth $g_d = g\left(1 - \dfrac dR\right)$ |
| Orbits | $v_o = \sqrt{\dfrac{GM}{r}}$ · $T^2 = \dfrac{4\pi^2}{GM}r^3$ · $E = -\dfrac{GMm}{2r}$ · $K = -E$, $U = 2E$ |
| Escape speed | $v_e = \sqrt{\dfrac{2GM}{R}} = \sqrt{2gR} = \sqrt2\,v_o$ (surface orbit) · Earth: $\approx 11.2$ km/s |
| Kepler II | areal velocity $\dfrac{dA}{dt} = \dfrac{L}{2m}$ = constant |
| Inside a uniform sphere | $g = \dfrac{GMr}{R^3}$ · shell: $g = 0$ inside |
:::

:::formula P07 · Properties of Solids & Liquids · page [[p07]]
| Result | Formula |
|---|---|
| Elasticity | $Y = \dfrac{FL}{A\,\Delta L}$ · $B = -\dfrac{\Delta P}{\Delta V/V}$ · energy density $= \tfrac12\,\text{stress}\times\text{strain}$ |
| Fluids | $P = P_0 + \rho gh$ · continuity $A_1v_1 = A_2v_2$ · Bernoulli $P + \tfrac12\rho v^2 + \rho gh$ = constant · Torricelli $v = \sqrt{2gh}$ |
| Viscosity | $F = \eta A\dfrac{dv}{dx}$ · Stokes $F = 6\pi\eta rv$ · terminal $v_t = \dfrac{2r^2(\rho - \sigma)g}{9\eta}$ |

| Thermal expansion | $\Delta L = L\alpha\Delta T$ · $\beta = 2\alpha$ · $\gamma = 3\alpha$ · thermal stress $= Y\alpha\Delta T$ |
| Heat | $Q = mc\Delta T$ · $Q = mL$ · conduction $\dfrac{dQ}{dt} = \dfrac{kA\Delta T}{L}$ · $R_{th} = \dfrac{L}{kA}$ |

:::

:::formula P08 · Thermodynamics · page [[p08]]
| Process | Work by gas $W$ | Key relation |
|---|---|---|
| First law | — | $\Delta Q = \Delta U + W$ · $\Delta U = nC_V\Delta T$ always (ideal gas) |
| Isothermal | $nRT\ln\dfrac{V_2}{V_1}$ | $PV$ = const · $\Delta U = 0$ |
| Adiabatic | $\dfrac{P_1V_1 - P_2V_2}{\gamma - 1}$ | $PV^\gamma$ = const · $TV^{\gamma - 1}$ = const · $Q = 0$ |
| Isobaric | $P\Delta V = nR\Delta T$ | $Q = nC_P\Delta T$ |
| Isochoric | 0 | $Q = nC_V\Delta T$ |
| Cyclic | area enclosed | $\Delta U = 0$ |

Carnot efficiency $\eta = 1 - \dfrac{T_2}{T_1}$ · refrigerator $\text{COP} = \dfrac{T_2}{T_1 - T_2}$ · $C_P - C_V = R$ · slope: adiabatic $= \gamma\times$ isothermal.
:::
